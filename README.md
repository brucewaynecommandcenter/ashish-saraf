# Ashish Saraf

Website of Ashish Saraf: industrialist, diplomat and philanthropist.

A single self-contained page (`index.html`), published with GitHub Pages.

## Photos

The hero portrait is built into the page. All other photos (gallery, press clippings, diplomatic photos)
load from the existing ashishsaraf.com server. To serve them from this site instead, copy the old site's
`images/`, `media/` and `gallery_image/` folders into this repo and set `IMG_BASE` to `''` near the top
of the script in `index.html`.

## Enquiry form

The form does not send messages yet. Connect it to a form service (for example Formspree) before launch.
